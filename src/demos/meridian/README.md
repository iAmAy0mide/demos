# Meridian Freight

Meridian Freight will be a logistics business site built in Phase 3. Tracking numbers, shipment states, and quote-flow data will be typed mock data in this folder.
## Meridian Freight

Meridian is a multi-page fictional freight-forwarding site built as a controlled shipping manifest: sea, air, road, clearance and warehousing pages share a precise document-led system, not a generic marketing template.

The home route map is a dependency-free SVG with CSS-drawn routes and keyboard-addressable destinations. Tracker records are typed mock data; query parameters keep each lookup shareable. The quote desk uses one reducer, validates each step, handles hazardous-cargo requirements and simulates a recorded request. Contact availability is calculated after mount in the Africa/Lagos timezone.
